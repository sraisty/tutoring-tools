# Tutoring worksheets

Begin worksheet production only on a user-requested worksheet run. For the first
authorized test run, work with one student only.

## Plan the session

Before planning a worksheet for any student, check the selected student's
folder for worksheet instructions. Apply any relevant preferences and ask the
user if they conflict with this week's request.

1. Use `~/Library/Mobile Documents/com~apple~CloudDocs/iCloudProjects/Tutoring`
   as the student materials root. Discover student folders under `students`.
2. Work through one student at a time and allow skips. Collect the session date,
   desired difficulty, and a list of topics with a practice page or problem
   count for each. Use information the user has already provided. Confirm the
   printable name if it is unclear. If the folder label includes grade
   information, use a name confirmed by the user.
3. For a page count, choose how many problems fit with suitable work space. For
   a problem count, use as many practice pages as needed for that space. If both
   counts conflict, ask which takes priority. Count only practice pages toward
   the requested page total.

## Write the problems and solutions

- Use the requested difficulty and any grade-level guidance to select problems.
  Progress from easier to harder within the topic. Keep grade labels out of the
  entire handout, including the answer key and Topic Instructions. Use a
  descriptive topic title free of remedial labels.
- Use the student's printable name for a child in a word problem. Invent a
  different child's name when another person is needed.
- Leave calculator questions out of the interview and calculator language out of
  the handout. Include units where relevant in both problems and solutions.
  Prefer exact answers. Specify rounding only when it is part of the skill or
  needed for practical measurement. Label diagrams `Not to scale` only when
  appropriate.
- In the answer key, include essential working, completed graphs for graphing
  questions, and reasoning for proofs. Identify multiple valid answers where
  applicable. For higher-level problems, briefly acknowledge alternative valid
  methods when appropriate.

## Lay out and save the PDF

Use single-sided pages with no blank separators. Put the student's name,
session date, and topic in every page header. Number every page. Keep each
question, diagram, and work area together on one page. Leave blank, unruled
space below each problem so the student can choose how to lay out their work.
Give geometry proofs substantially more space than short calculations. Provide
a suitably scaled x-y grid with room for the student's graph whenever graphing
is required. Make text, diagrams, and grids readable in black-and-white print.

Use this section order in each PDF:

1. Practice pages.
2. Answer Key, starting on a new page and continuing as needed.
3. Topic Instructions, starting on a new page at the end. Use `Topic
   Instructions` as the heading. Explain how to solve the types of problems in
   the handout. Aim for one legible page, using columns or modestly smaller
   graphs when helpful. Add a page only if a single page would be hard to read.

Save one PDF per topic under `students/<STUDENT NAME>/worksheets`, relative to
the student materials root. Use the session date in the filename, as in
`2026-11-18_Maya_Graphing-Linear-Equations.pdf`. Store the editable questions,
layout, and any required assets in the student's sibling `worksheet-sources`
folder, using an existing dedicated source folder if present. Keep personalized
files in the student materials root. On revisions, preserve prior PDFs and
sources. Use the next unused suffix, such as `_v2`, for the revised PDF and its
matching source.

## Verify before delivery

- Double-check every answer, including graphs, proof reasoning, and units. Match
  answer numbering to the practice problems and remove duplicate problems within
  each handout.
- Render and inspect every page. Check print legibility, blank work space,
  grid scale and room, headers, page numbers, page breaks, and section order.
- Confirm the session date and topic match the filename and page headers. Check
  that each topic has a PDF with all three sections and a matching editable
  source that can be used for revisions.
